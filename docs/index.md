# Welcome to em_inspection

**em_inspection** is a specialized Python toolkit for interactive inspection, alignment verification, and coarse-offset calculations for Serial Block-Face Electron Microscopy (SBEM) datasets.

## Key Features

- **Parser for SBEM Datasets**: Standardized file structures, metadata, and section indexing.
- **Interactive Inspection**: Dashboard UI for reviewing tile overlaps and outlier regions.
- **Quality Control**: Automated coarse offset calculation, error metrics, and mask generation.
